# 武汉数命 SPU 城市 AI 接待员

SAIG 数命SPU国际AI大赛线上赛个人作品。页面是一个手机优先的中文接待台，不登录、不连数据库。四项必答都由随页面打包的知识库完成，没有密钥也能演示。

形象使用赛事材料里的「武汉SPU城市AI接待员」官方虚拟形象。

## 四项功能

每项都对应页面上的一个入口：

1. **介绍武汉**：两江三镇、市花市树、城市精神，以及概览里点名的 5A 景区。人口和经济是 2020 年口径，问到才展开，并标明年份。
2. **介绍数命SPU社区**：江岸智民里与光谷创新天地，两处合计近 8000 平方米；BIWEN、AI 工坊、FDE、OPC。
3. **武汉行程**：选择 1 / 2 / 3 天，以及人文、自然、美食或综合。行程只来自《2026武汉旅游产品手册》里的线路和街区，例如江汉揽胜、荆楚文脉、地铁阅城、户部巷、东湖、木兰。
4. **介绍数命SPU以及 SAIG**：Super Person Unit、五项能力、U = PS，以及说明文书中的线上赛、48 小时线下赛和赛后市场验证。官网若有另一套赛程，会并列写出，不合成一个折中答案。

自由输入也可以。对不上材料时，接待员会说明不确定。

## 本地运行

需要 Node.js 20 或更高。

```bash
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:4179>。

```bash
npm run check   # 核对四项回答是否含关键事实
npm run build   # 产物在 dist/，资源使用相对路径
npm run preview
```

部署到 GitHub Pages 时，发布 `dist/` 目录即可。不要设置绝对路径的 `base`，当前已经是 `./`。

可选的模型接口写在页面最下方，密钥只进这台浏览器的 localStorage，仓库里没有密钥。不填也能完整演示。

## 60–90 秒演示稿

对着镜头，按这个顺序走完四项。语速正常大约 80 秒。

1. **0–8 秒**  
   打开页面，让官方形象先入画。说：「这是武汉数命 SPU 城市 AI 接待员。上面四个入口，就是线上赛要的四项功能。它不联网编答案。」

2. **8–25 秒 · 介绍武汉**  
   点「介绍武汉」。等「江城」「两江三镇」「敢为人先，追求卓越」出现。指一下来源「武汉概览」。补一句：「人口我标的是 2020 年的 1232.65 万，手册序言另有 1400 多万，两套数字不合并。」

3. **25–42 秒 · 数命SPU社区**  
   点「数命SPU社区」。画面里要出现智民里、光谷创新天地、近 8000 平方米、BIWEN。说：「社区用真实订单把人养成能交付的 SPU，培养 FDE，也支持一人公司 OPC。」

4. **42–65 秒 · 武汉行程**  
   点「武汉行程」，选 **2 天**、**人文**，点生成。第一天要看见黄鹤楼和 70 元门票，第二天要看见湖北省博物馆和「提前预约」。说：「这是手册里的江汉揽胜和荆楚文脉。没写清的车程，它不编。」

5. **65–85 秒 · 数命SPU 与 SAIG**  
   点第四个入口。先指五项能力：判断、调用 AI、组织任务、交付、负责。再指 2026 年 12 月 18 日开赛、48 小时、出资 100 万美元。最后停在黄色提示上：「说明文书是 48 小时，官网页面写成平和打包厂、两天 16 小时。它把两套都说出来，报名以官网和 developer@markyin.com 为准。」

6. **85–90 秒**  
   画面落到页脚「雷静 / Leinstein」，结束。

如果还剩几秒，可以在输入框打「黄鹤楼门票」，让 70 元和蛇山地址再出现一次。

## 故意没有写成定论的事实

- **2020 年 GDP、社零和地铁运营里程**只在问到人口或经济时出现，并写明是年鉴里的 2020 年，其中 GDP 为下降 4.7%。不把它们说成 2026 年现状。
- **常住人口**同时保留概览的 1232.65 万（2020 年末）和手册序言的「1400 多万市民」，不判断哪一个是现在的常住人口。
- **线下赛日程**保留说明文书的 48 小时（2026-12-18 12:00 至 2026-12-20 12:00），同时列出官网页面的另一种说法：平和打包厂、两天共 16 小时、每天 10:00–18:00、市场检验至 2027-03-31、现场 40% 与市场 60%。不合并。
- **报名是否仍开放**保留说明文书的日期：2026年11月20日报名截止，2026年11月23日公布入围名单。同时列出官网选手报名区的原文：「报名顺延中」「报名继续开放，截止时间以赛事公告为准」。页面没有另给新的截止时刻，不编一个新日期。以官网和 developer@markyin.com 为准。
- **人气榜点赞统计截止**按官网原文：2026年11月20日23:59:59（北京时间，UTC+8）。不把报名顺延理解成点赞截止也顺延。
- **100 万美元**在说明里是「出资举办」，在官网页面是奖池价值并区分现金与模型额度。不把它说成两笔，也不逐名拆奖金。
- **月薪 1 万美元及社保**按说明写成岗位探索设想，不是录取通知。
- **知音号、汉秀、编钟演出、两江夜游**的票价，材料没有写成固定数字，回答里不报价。
- **江汉关**专页写「需预约」，地铁三日游写「现场登记即可」。两句都保留，并建议以当天馆方为准。
- **社区**只采用「两处合计近 8000 平方米」。设计图没有可引用的分栋面积；报道里的街区长度、机器人咖啡等，不写进回答。
- **景点之间的车程、排队分钟、酒店房价、实时天气**一律不编。气候只有概览里的多年概括。
- **SPU 的中文**采用说明里的「超级个体单元」，不用别的译名。

咨询邮箱只使用官网页面中的 developer@markyin.com。没有电话。
